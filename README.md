## 📌 บทนำและภาพรวมระบบ

ComTrade คือเว็บแอปพลิเคชัน Full-Stack สำหรับซื้อขายคอมพิวเตอร์และอุปกรณ์มือสอง พัฒนาด้วย Node.js, Express และ PostgreSQL เชื่อมต่อ RESTful API ครบวงจร ตอบสนองรวดเร็ว ปลอดภัยด้วยการป้องกัน SQL Injection, Parameterized Queries และ JWT Authentication

ประกอบด้วยระบบหลัก:
1. **หน้าร้าน (Storefront):** ค้นหาและกรองสเปกละเอียด (CPU, RAM, GPU, ดัชนีสภาพเครื่อง %, ช่วงราคา) อัปเดตผลลัพธ์แบบ SPA-like
2. **หน้ารายละเอียดสินค้า (Product Detail):** แสดงภาพถ่ายจริง ตารางสเปกเจาะลึก ป้ายสภาพเครื่อง
3. **ระบบตะกร้าและคำสั่งซื้อ (Cart & Orders):** คำนวณราคาและค่าส่งฝั่ง Server ป้องกันการดัดแปลงราคา รองรับระบบจัดส่งฟรีเมื่อช้อปครบ 50,000 บาท
4. **ระบบสมาชิกและความปลอดภัย (Auth & Security):** สมัครสมาชิก เข้าสู่ระบบ แฮชรหัสผ่านด้วย `bcryptjs` ออก Stateless `JWT` ควบคุมสิทธิ์ (RBAC)
5. **ระบบบริหารจัดการหลังบ้าน (Admin Dashboard):** จัดการสินค้าในคลัง (CRUD), อัปโหลดรูปภาพสินค้าด้วย Multer, ปรับเปลี่ยนสถานะคำสั่งซื้อแบบ Real-time

## ความสามารถ

- ค้นหาและกรองสินค้าตามคำค้นหา หมวดหมู่ RAM การ์ดจอ สภาพ และราคา
- ดูรายละเอียดสินค้าและเพิ่มสินค้าลงในตะกร้าเพื่อสร้างคำสั่งซื้อ
- สมัครสมาชิกและเข้าสู่ระบบ โดยรหัสผ่านถูกแฮชก่อนบันทึก
- ตรวจสอบรายการและสถานะคำสั่งซื้อของลูกค้า
- ผู้ดูแลเพิ่ม แก้ไข และลบสินค้า อัปโหลดรูปสินค้า และเปลี่ยนสถานะคำสั่งซื้อ
- ค่าจัดส่ง 150 บาทเมื่อยอดสินค้าต่ำกว่า 50,000 บาท; ยอดตั้งแต่ 50,000 บาทขึ้นไปจัดส่งฟรี

## เทคโนโลยี

## เริ่มต้นใช้งาน

ต้องติดตั้ง Node.js และ npm ก่อน จากโฟลเดอร์โปรเจกต์ให้รัน:

```bash
npm install
npm run seed   # เพิ่มข้อมูลสินค้าตัวอย่าง 10 รายการเข้าสู่ฐานข้อมูล
npm start      # หรือ npm run dev สำหรับโหมดพัฒนา
```

ก่อนเริ่มใช้งาน ให้สร้างไฟล์ `.env` ในโฟลเดอร์โปรเจกต์และกำหนด `DATABASE_URL` เป็น connection string ที่ได้จากผู้ให้บริการ PostgreSQL:

```env
DATABASE_URL=postgresql://USER:PASSWORD@HOST:PORT/DATABASE
```

ตรวจสอบว่าฐานข้อมูลเปิดใช้งานอยู่และอนุญาตการเชื่อมต่อจากเครือข่าย/ที่อยู่ IP ของเครื่องที่รันแอป ค่า connection string และการตั้งค่า SSL ควรใช้ตามที่ผู้ให้บริการกำหนด ห้ามเผยแพร่ไฟล์ `.env`

เปิดหน้าร้านที่ <http://localhost:3000> และหน้าแอดมินที่ <http://localhost:3000/admin.html> โดยเซิร์ฟเวอร์ใช้พอร์ตจากตัวแปร `PORT` หากกำหนดไว้ มิฉะนั้นใช้พอร์ต 3000

เมื่อเชื่อมต่อ PostgreSQL ได้ ระบบจะสร้างตารางที่จำเป็นและผู้ใช้แอดมินตัวอย่างโดยอัตโนมัติ:

- อีเมล: `admin@comtrade.local`
- รหัสผ่าน: `admin1234`

บัญชีนี้มีไว้สำหรับทดลองในเครื่องเท่านั้น ควรเปลี่ยนหรือลบข้อมูลบัญชีตัวอย่างก่อนนำระบบไปใช้งานจริง และกำหนด `JWT_SECRET` เป็นค่าสุ่มที่เก็บเป็นความลับก่อนเปิดให้ใช้งาน

## หน้าหลัก

- `index.html` — รายการสินค้า การค้นหา/ตัวกรอง และตะกร้า
- `product.html` — รายละเอียดสินค้า
- `login.html` — สมัครสมาชิกและเข้าสู่ระบบ
- `orders.html` — คำสั่งซื้อของลูกค้า
- `admin.html` — จัดการสินค้าและคำสั่งซื้อ (สำหรับแอดมิน)

## API โดยสรุป

เส้นทางที่ต้องเข้าสู่ระบบรับ JWT ผ่าน `Authorization: Bearer <token>`; เส้นทางที่ระบุว่าแอดมินต้องใช้บัญชีผู้ดูแล

| Method | Path | การใช้งาน |
| --- | --- | --- |
| POST | `/api/auth/register` | สมัครสมาชิก |
| POST | `/api/auth/login` | เข้าสู่ระบบและรับ token |
| GET | `/api/products` | ดูสินค้า; รองรับ `q`, `cat`, `ram`, `gpu`, `cond`, `price` |
| GET | `/api/products/:id` | ดูรายละเอียดสินค้า |
| GET | `/api/stats` | ดูสถิติสินค้า หมวดหมู่ สภาพสินค้า และสมาชิก |
| POST | `/api/orders` | สร้างคำสั่งซื้อ (ต้องเข้าสู่ระบบ) |
| GET | `/api/orders/me` | ดูคำสั่งซื้อของตนเอง (ต้องเข้าสู่ระบบ) |
| POST | `/api/products` | เพิ่มสินค้า (แอดมิน) |
| PUT / DELETE | `/api/products/:id` | แก้ไข/ลบสินค้า (แอดมิน) |
| GET | `/api/orders` | ดูคำสั่งซื้อทั้งหมด (แอดมิน) |
| PATCH | `/api/orders/:id/status` | เปลี่ยนสถานะคำสั่งซื้อ (แอดมิน) |
| POST | `/api/upload` | อัปโหลดรูปสินค้า (แอดมิน; JPG, PNG หรือ WEBP ไม่เกิน 2 MB) |

สถานะคำสั่งซื้อที่รองรับ: `รอชำระเงิน`, `ชำระแล้ว`, `จัดส่งแล้ว` และ `ยกเลิก`

## หมายเหตุการจัดเก็บข้อมูล

ข้อมูลจะถูกจัดเก็บใน PostgreSQL ส่วนรูปที่อัปโหลดจะอยู่ใน `public/uploads/` หากนำไปโฮสต์บนระบบไฟล์ชั่วคราว รูปที่เพิ่มอาจหายเมื่อเซิร์ฟเวอร์รีสตาร์ต ควรใช้พื้นที่จัดเก็บแบบถาวรและสำรองฐานข้อมูลสำหรับการใช้งานจริง
